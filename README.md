# 🖥️ Windows Server & Active Directory Lab

This was one of my hands-on projects for my Windows Server class. I built and configured a Windows Server environment along with Windows client virtual machines and worked through the different parts of setting up and managing a domain.

## 🔧 What I Worked On

- Windows Server installation and configuration
- Windows client virtual machines
- Active Directory Domain Services
- Organizational Units (OUs)
- Users and security groups
- DNS and DHCP
- File sharing and permissions
- Network and client configuration
- Group Policy
- PowerShell and Command Prompt

## 💡 What I Learned

This project gave me more practice working with Windows Server and Active Directory in an actual virtual environment. I also got more experience troubleshooting when something didn't work the way it was supposed to, which was a big part of getting everything configured correctly.
